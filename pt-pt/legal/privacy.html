Recolha de dados neste site

Este site é um site estático alojado no GitHub Pages. Não recolhemos, armazenamos nem processamos dados pessoais através deste site.

Não utilizamos cookies, ferramentas de análise ou quaisquer mecanismos de rastreamento.

Ficheiros de registo do servidor

O fornecedor de alojamento (GitHub) pode recolher e armazenar automaticamente informações nos ficheiros de registo do servidor. Isto pode incluir:

  • Tipo e versão do navegador
  • Sistema operativo
  • URL de referência
  • Nome do anfitrião do computador a aceder
  • Hora do pedido ao servidor
  • Endereço IP

Estes dados não são combinados com outras fontes de dados e são armazenados pelo GitHub de acordo com a sua política de privacidade.

Contacto

Se nos contactar por e-mail, a sua mensagem e os dados que fornecer (incluindo endereço de e-mail e nome) serão armazenados para fins de processamento do seu pedido e para possíveis perguntas de acompanhamento. Não partilhamos estes dados sem o seu consentimento.

Os seus direitos

Tem o direito de:

  • Solicitar informações sobre dados pessoais armazenados
  • Solicitar correção de dados incorretos
  • Solicitar eliminação dos seus dados
  • Solicitar restrição do tratamento de dados
  • Opor-se ao tratamento de dados
  • Solicitar portabilidade de dados
