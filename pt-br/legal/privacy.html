Coleta de dados neste site

Este site é um site estático hospedado no GitHub Pages. Não coletamos, armazenamos nem processamos dados pessoais por este site.

Não usamos cookies, ferramentas de análise ou quaisquer mecanismos de rastreamento.

Arquivos de log do servidor

O provedor de hospedagem (GitHub) pode coletar e armazenar automaticamente informações nos arquivos de log do servidor. Isso pode incluir:

  • Tipo e versão do navegador
  • Sistema operacional
  • URL de referência
  • Nome do host do computador acessando
  • Hora da solicitação do servidor
  • Endereço IP

Esses dados não são combinados com outras fontes de dados e são armazenados pelo GitHub de acordo com sua política de privacidade.

Contato

Se você nos contatar por e-mail, sua mensagem e os dados que você fornecer (incluindo endereço de e-mail e nome) serão armazenados para fins de processamento de sua consulta e para possíveis perguntas de acompanhamento. Não compartilhamos esses dados sem o seu consentimento.

Seus direitos

Você tem o direito de:

  • Solicitar informações sobre dados pessoais armazenados
  • Solicitar correção de dados incorretos
  • Solicitar exclusão de seus dados
  • Solicitar restrição do processamento de dados
  • Contestar o processamento de dados
  • Solicitar portabilidade de dados
