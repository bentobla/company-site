Privatlivserklæring for tøwer

2026-10-24

1. Ansvarlig og anvendelse

Denne erklæring gælder tøwer til Android og iOS. Dataansvarlig er Tobias Blankenhorn, Jetzt & Dahanna Technologies, Richard-Wagner-Str. 17/1, 71116 Gärtringen, Tyskland. Kontakt: info@jetztunddahanna.com.

2. Lokale data

Spillet kræver ingen konto og fungerer offline. Gemte spil, aktive vagter, resultater, point, stjerner, medaljer, oplåst indhold og indstillinger gemmes på enheden. Et valgfrit visningsnavn er også lokalt; dit rigtige navn er ikke nødvendigt. Vi driver ingen spilserver og uploader ikke automatisk spil- eller diagnosedata. Appen tilgår ikke kontakter, kamera, mikrofon, fotos eller enhedens præcise placering og spørger ikke om alder eller fødselsdato.

3. Annoncer og engangskøb

Gratisversionen bruger Google AdMob med ikke-personaliserede annonceanmodninger. Google kan behandle IP-adresse, enheds- og appoplysninger, tilladte identifikatorer, annonceinteraktioner og tekniske diagnoser til annoncer, måling, sikkerhed og forebyggelse af svindel. Ikke-personaliseret betyder ikke uden persondata. Et valgfrit engangskøb fjerner annoncer permanent uden abonnement. Apple eller Google håndterer køb og gendannelse via butikskontoen; vi får ikke kort- eller bankoplysninger. Nødvendig købsstatus, produkt- og transaktions-id, butik og gyldighed gemmes lokalt, ikke rå kvitteringer eller betalingstokens. Efter aktivering af reklamefri adgang sendes ingen nye annonceanmodninger; tidligere behandlede data slettes ikke dermed.

4. Diagnostik og kontakt

Diagnoseeksport opretter en lokal fil med appversion og build-id, mission, regelversion, simuleringstidspunkt, resultatstatus, årsag og point. Navn og fuld spilfil medtages ikke; filen sendes ikke automatisk. Ved e-mail behandler vi adresse, besked og vedhæftninger for at svare og løse problemer; vores mailtjeneste håndterer leveringen. Beskeder slettes efter sagen og opfølgning, medmindre lovkrav eller retskrav kræver opbevaring.

5. Formål og retsgrundlag

App- og købsfunktioner og tilknyttede henvendelser: GDPR artikel 6, stk. 1, litra b. Anden support, sikker drift og svindelforebyggelse: litra f, vores legitime interesse i at svare og beskytte tjenesten. Lovpligtig opbevaring: litra c. Annoncebehandling og adgang til enhedsidentifikatorer kræver samtykke, hvor loven kræver det. Kontaktoplysninger er frivillige, men kan være nødvendige for svar. Ingen automatiske afgørelser med retlige eller tilsvarende væsentlige følger.

6. Opbevaring og lokal sletning

Lokale data bliver indtil ændring eller sletning. Nulstilling af fremskridt fjerner ikke alle indstillinger, navn, købsstatus eller eksporteret diagnostik. Appen kan have en lokal kopi af forrige spilfil. Ryd alle appdata på Android eller slet appen med dens data på iOS; aflastning alene sletter ikke alt. Håndter systembackups og eksporter separat. Butiksdata følger Apple eller Googles opbevaringsregler.

7. Sletningsanmodninger og rettigheder

Vi kan kun slette data, vi selv har, såsom supportmails, med forbehold for opbevaringskrav. Vi har ingen direkte adgang til Googles AdMob-data og kan ikke selv slette dem. Send sådanne anmodninger til Googles privatlivskontakter. Vores lovbestemte databeskyttelsespligter består. Vi kan ikke fjernslette lokale data. På understøttede Android-enheder kan annonce-id nulstilles eller slettes under Privatliv / Annoncer; navnene varierer. Google – Min aktivitet omfatter ikke alle AdMob-data. Hverken værktøjet eller sletning af id garanterer sletning af alle udbyderdata. Se Googles privatlivscenter, vejledning til annonce-id og privatlivskontakter. Du kan efter lovens betingelser anmode os om indsigt, rettelse, sletning, begrænsning, dataportabilitet og gøre indsigelse. Samtykke kan trækkes tilbage fremadrettet. Du kan klage til en tilsynsmyndighed, herunder myndigheden i Baden-Württemberg. Skriv til vores e-mail; ingen konto eller ekstra formular er nødvendig.

8. Børn, sikkerhed og udbydere

Oplysningerne gælder også børn. Forældre kan håndtere lokale data og kontakte os. Ikke-personaliserede annoncer kan stadig indebære teknisk databehandling. Enhedens sikkerhed og backups er vigtige; absolut sikkerhed kan ikke garanteres. Vi sælger ikke persondata. Apple og Google behandler også installationer, køb og systemdiagnostik, du vælger at dele. Udbyderne kan behandle data uden for EØS; deres politikker beskriver opbevaring og overførselsgarantier såsom tilstrækkelighedsafgørelser eller standardkontraktbestemmelser.

9. Denne side og ændringer

Siden har ingen scripts, cookies, web-lagring eller analyseværktøjer. GitHub Pages behandler forbindelsesdata, især IP-adresser, til levering og sikkerhed på grundlag af vores legitime interesse, GDPR artikel 6, stk. 1, litra f. Opbevaring følger GitHubs politik. Vi opdaterer erklæringen ved ændringer; adressen bevares.
